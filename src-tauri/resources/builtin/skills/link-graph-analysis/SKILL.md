# 关联脉络梳理

围绕一个主题在知识库中做只读探索，**本 Skill 不执行任何写入**。

分三步：

1. **定位核心笔记**：用搜索找到主题下被引用最多、内容最实的笔记。判断「内容最实」要看正文是否有实质论述，不能只看标题相关。
2. **梳理关系**：读这些笔记的出链与入链，归纳为若干**脉络簇**——每个簇是一组围绕同一子问题互相链接的笔记。
3. **识别缺口**：指出主题上明显缺失的环节。

输出要求：

- `coreNodes`：核心笔记列表，每条说明它在这个主题里承担什么角色（入口 / 论证 / 案例 / 反例）。
- `clusters`：脉络簇，每簇给出名称、包含的笔记、以及这簇回答的是哪个子问题。
- `gaps`：知识缺口，每条说明「缺的是什么」以及「可以补的入口笔记」。
- **必须区分「图谱上相连」和「内容上相关」**：仅有链接关系但内容无实质关联的，不要算作同一簇，并明确指出这种弱连接。
- 关联不足时如实说明「该主题在库内尚未形成脉络」，不要为了凑结构而强行分组。
- 最后给出建议补链的位置（哪两篇笔记之间值得加 `[[双链]]`），但不要代替用户写入。
