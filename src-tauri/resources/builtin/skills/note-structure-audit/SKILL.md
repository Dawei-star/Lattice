# 笔记结构体检

只处理单篇笔记。先完整读取内容，不要凭标题猜测结构。

按以下顺序检查并逐条列出问题：

1. **标题层级**：H1 是否唯一且与文件名语义一致；是否存在跳级（H2 直接到 H4）。
2. **双链**：正文中的 `[[...]]` 是否指向真实存在的笔记；是否存在指向已删除或空白笔记的死链。
3. **标签**：是否出现在正文行内或行首；是否有疑似十六进制色值（如 `#fff`、`#e2e`）被误当标签——带数字时只认 6/8 位，纯字母时 3/6/8 位都算色值。
4. **待办**：`- [ ]` 是否长期未闭环；是否存在没有归属项目的孤立待办。
5. **元信息**：需要归属项目但未声明 `project` 的笔记。

输出要求：

- 每条问题必须给出**原文位置**（引用具体行）和**判断依据**，不得只给结论。
- 修复建议写成 `proposedEdits`，逐项包含 `path`、原文片段、替换后片段。
- 所有写入动作必须走确认流程，先展示清单再改。
- 不要重写笔记的思路和措辞，只修结构问题（层级、链接格式、标签位置）。
