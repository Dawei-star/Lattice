# 决策记录归档

从指定笔记（可多篇）中抽取决策，整理成结构化记录。

每条决策必须写清五要素，缺项就标 `未记录` 而不要编造：

- **决策内容**：一句话可复述的结论。
- **背景**：为什么需要做这个决定，触发它的问题是什么。
- **候选与取舍**：考虑过哪些方案、为什么选了现在这个、放弃了什么。原文没写就留空并提示用户补充。
- **决定日期**：只写原文能确证的日期；只能推断到月份就写月份。
- **影响与可逆性**：改动成本、是否容易回滚。

同时单独整理：

- **待验证假设**：决策里依赖但尚未验证的前提，逐条列出。
- **遗留问题**：明确标记「未解决」的争议点。

输出要求：

- 每条决策必须附**来源引用**（哪篇笔记、哪一段），无法追溯的决策不要收录。
- 区分「已经拍板的决定」和「讨论中的倾向」，后者放 openQuestions，不要写成决策。
- 创建新笔记前先展示草稿，等确认。
- 不要在归档过程中顺手修改原笔记的措辞。
