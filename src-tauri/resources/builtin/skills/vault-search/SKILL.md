# 知识库检索

先使用搜索动作获取候选笔记，再按需要读取原文。回答中的重要结论必须能对应到搜索或读取结果。

区分原文事实、模型推断和未验证信息。找不到足够证据时，明确说资料不足，不要虚构引用。
