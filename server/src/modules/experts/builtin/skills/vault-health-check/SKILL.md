# 知识库巡检

对整个知识库做只读体检，**本 Skill 不执行任何写入、移动或删除**。

用搜索和图关系分四类输出，每条都要带 `path` 和判断依据：

1. **孤立笔记（orphans）**：没有任何入链也没有出链的笔记。
2. **断链（brokenLinks）**：正文 `[[...]]` 指向不存在的笔记。区分两种情况——**拼写错误**（与已有笔记仅差字符）和**尚未创建**（确实是新概念）。两者处理方式不同，不要混为一谈。
3. **重复内容（duplicates）**：标题高度相似或正文大段重叠的笔记。给出重叠比例，不要凭印象断言重复。
4. **僵尸笔记（stale）**：长期未修改且无链接指向的内容。列出修改时间供用户判断，不要建议删除。

输出要求：

- 按严重程度分组，每组内按影响面排序。
- 不确定是否重复的笔记放入「需人工确认」，不要直接下结论。
- 结尾给出**建议的下一步动作清单**（只描述意图，不生成执行计划），由用户决定是否进入整理流程。
- 报告开头必须说明本次巡检覆盖的笔记总数与搜索范围，避免用户误以为已覆盖全库。
