01 设计哲学与核心原则

原则含义
本地优先所有数据存储在用户本地磁盘，断网完全可用，不依赖任何云端服务
数据归用户笔记以 Markdown 文件直接存于 Vault 目录，可用任意编辑器打开，不锁定在数据库黑盒里
核心零服务器桌面核心后端运行在 Tauri Rust 进程内；MCP sidecar 和 Ollama 是可选外部运行时
AI 可离线配置并运行本地 Ollama 后，断网也能用 AI 问答和写作助手；云端模型可选
插件受控执行QuickJS 只负责脚本运行；权限桥接、签名和高风险进程隔离共同构成安全边界
零厂商锁定全栈开源，数据格式开放，用户可随时迁移到其他工具
不做过度设计单机模式不引入协作、同步、移动端，保持架构精简

01A 架构契约与不变量

以下约束优先于具体实现。实现偏离时，必须先更新本节和对应 ADR。

契约定义
持久化真源Vault 中的 .md、.canvas 和附件是唯一持久化真源；BlockSuite 文档和 SQLite 都是可重建的派生状态。
单写入入口UI、AI、MCP、插件和外部文件变更最终都经过 Rust WorkspaceService；外部进程不得直接修改 lattice.db。
投影一致性文件写入成功不等于索引已完成；索引、链接、向量和图谱更新必须有状态、重试和可观测的后台任务。
编辑器保真Markdown 不支持的语法以原文块或扩展节点保留，禁止静默丢失；互转由固定语料库验证。
并发策略同一 Vault 默认单实例写入；第二实例和独立 MCP 进程只能通过受控 API 访问，冲突使用内容哈希检测。
派生索引全文索引、链接、标签、向量和健康检查结果带来源哈希/版本，必要时可删除并从 Vault 重建。
隐私边界“本地优先”不等于“内容已加密”。启用内容保密时，必须同时覆盖 Markdown、版本快照、附件和索引。
推荐的写入边界

桌面 UI、AI、MCP sidecar、插件桥接层和 watcher 都调用 WorkspaceService；它负责 Vault 原子写入、哈希冲突、快照、审计和派生任务排队。sidecar 不直接打开 Vault 或 SQLite。

04 五层架构详解

L1 数据层 Storage

Vault 文件是用户数据的持久化真源；SQLite、向量和图谱都是可删除重建的派生投影。所有读写都由受控服务访问，不直接暴露给前端或插件。

组件职责关键设计
SQLite索引、标签、AI 配置、MCP 审计、笔记元数据FTS5 trigram 分词（中文子串匹配）+ sqlite-vec 向量索引同库
文件系统Markdown 原文、Canvas 白板、图片附件用户可直接用其他编辑器打开，不锁定在数据库
加密API Key 密文存储；可选内容加密密钥用系统 Keychain；内容加密需覆盖 Markdown、附件、快照和索引
版本快照笔记历史版本与恢复增量 diff + 完整快照、来源哈希和保留策略

L2 引擎层 Engine

核心引擎，提供编辑器、双链、事件分发等基础能力。

组件职责关键设计
BlockSuite块编辑器运行时投影Page/Edgeless；不取代 Markdown/.canvas 真源
双链引擎[[标题]] 双向链接 / ![[标题]] 嵌入引用作为 BlockSuite 自定义 Block 实现，支持嵌套+循环检测
事件总线模块间解耦通信发布订阅模式，笔记变更→索引更新→图谱刷新→AI 增量
Markdown 互转BlockSuite 投影 ↔ .md 文件未知块保留原文，以语义往返测试作为门禁

L3 能力层 Capabilities

具体业务能力，调用 L2 引擎和 L1 数据。

05 核心模块设计：编辑器引擎

BlockSuite 数据模型与双链扩展

设计要点：双链和嵌入不是独立渲染逻辑，而是 BlockSuite 的自定义 Block 类型。这样编辑、搜索、AI 索引、图谱可视化都基于统一的 Block 模型，不会出现数据不一致。

06 核心模块设计：AI 引擎

AI 混合检索 + RAG 管线
保留的核心设计

原项目的 FTS5 + 向量混合检索思路继续保留，但 RRF、分块和 top_n 都作为可版本化参数，通过 golden set 和性能基准调优。新增本地模型支持（Ollama）和 sqlite-vec 集成，使 AI 在满足本地运行时条件时可以离线工作。

08 核心模块设计：MCP 双向集成

MCP Server + Client 双向数据流
为什么 MCP 是生态关键

MCP 让 Lattice 既是知识提供者（Claude/Cursor 可以搜你的笔记），又是工具消费者（AI 助手可以操作文件、搜索网络、查 Git）。这是笔记软件成为 AI Agent 知识库的核心协议，也是单机生态的基石。

SQLite 表结构（核心表）

-- 笔记元数据（原文在文件系统）
CREATE TABLE notes (
  path        TEXT NOT NULL,           -- Vault 内相对路径
  title       TEXT,
  content_hash TEXT NOT NULL,
  parser_version TEXT NOT NULL,
  created_at  TEXT NOT NULL,
  updated_at  TEXT NOT NULL,
  word_count  INTEGER DEFAULT 0,
  is_archived INTEGER DEFAULT 0,
  index_state TEXT NOT NULL DEFAULT 'pending',
  PRIMARY KEY (path)
);

-- 每个连接都必须开启；迁移和测试均验证外键约束生效。
PRAGMA foreign_keys = ON;

-- 全文检索（FTS5 trigram 分词）
CREATE VIRTUAL TABLE notes_fts USING fts5(
  path, title, content,
  tokenize = 'trigram'               -- 中文子串匹配
);

-- 向量索引（sqlite-vec）
CREATE TABLE note_chunks (
  note_path TEXT NOT NULL,
  chunk_id INTEGER NOT NULL,
  source_hash TEXT NOT NULL,
  chunker_version TEXT NOT NULL,
  content TEXT NOT NULL,
  PRIMARY KEY (note_path, chunk_id),
  FOREIGN KEY (note_path) REFERENCES notes(path) ON DELETE CASCADE
);

CREATE VIRTUAL TABLE note_embeddings USING vec0(
  note_path TEXT,
  chunk_id INTEGER,
  embedding FLOAT[384]               -- 维度按模型版本配置
);

-- 双链关系
CREATE TABLE links (
  source_path TEXT NOT NULL,
  target_path TEXT,
  anchor      TEXT,                  -- [[标题#锚点]]
  type        TEXT DEFAULT 'link',   -- link | embed
  is_dangling  INTEGER DEFAULT 0,   -- 悬空链接
  UNIQUE (source_path, target_path, anchor, type),
  FOREIGN KEY (source_path) REFERENCES notes(path) ON DELETE CASCADE
);
CREATE INDEX ix_links_target ON links(target_path);

-- 标签
CREATE TABLE tags (
  name       TEXT PRIMARY KEY,      -- 支持 嵌套/路径
  created_at TEXT NOT NULL
);

CREATE TABLE note_tags (
  note_path TEXT NOT NULL,
  tag_name TEXT NOT NULL,
  PRIMARY KEY (note_path, tag_name),
  FOREIGN KEY (note_path) REFERENCES notes(path) ON DELETE CASCADE,
  FOREIGN KEY (tag_name) REFERENCES tags(name) ON DELETE CASCADE
);

-- AI 会话
CREATE TABLE ai_sessions (
  id         TEXT PRIMARY KEY,
  title      TEXT,
  messages   TEXT NOT NULL,         -- JSON
  created_at TEXT NOT NULL
);

-- AI 配置（密文存储）
CREATE TABLE ai_settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL                -- AES-256-GCM 加密
);

-- MCP 审计日志
CREATE TABLE mcp_audit (
  id         INTEGER PRIMARY KEY,
  tool       TEXT NOT NULL,
  params     TEXT,
  result     TEXT,
  principal  TEXT,                  -- 调用者身份
  decision   TEXT NOT NULL,         -- allowed | denied | confirmed
  redacted   INTEGER NOT NULL DEFAULT 1,
  created_at TEXT NOT NULL
);

-- 笔记版本快照索引
CREATE TABLE note_versions (
  id         INTEGER PRIMARY KEY,
  note_path  TEXT NOT NULL,
  version    INTEGER NOT NULL,
  diff_path  TEXT NOT NULL,          -- .lattice/versions/ 下的路径
  created_at TEXT NOT NULL
);

-- 可恢复的派生任务：索引、embedding、快照和健康扫描不能只靠内存事件。
CREATE TABLE jobs (
  id          TEXT PRIMARY KEY,
  kind        TEXT NOT NULL,
  subject     TEXT NOT NULL,
  source_hash TEXT,
  state       TEXT NOT NULL,         -- pending | running | done | failed | cancelled
  attempts    INTEGER NOT NULL DEFAULT 0,
  error       TEXT,
  created_at  TEXT NOT NULL,
  updated_at  TEXT NOT NULL
);

10 安全设计

威胁防御措施实现层
XSS 注入自研白名单 Markdown 消毒器，过滤危险 HTML/JSL2 引擎
MCP 越权写入sidecar 默认只读；按客户端/工具/路径授权，确认、审计和撤销L3 能力
MCP/AI prompt injection外部内容与系统指令分层，工具结果大小/域名/路径受限L3 能力
AI 篡改笔记写入流程：预览→确认→事务→审计→可撤销L3 能力
插件越权QuickJS + 最小权限桥接 + 签名；高风险能力独立进程L3 能力
凭证泄露API Key 只存系统 Keychain；SQLite 只存引用或密文L1 数据
网络/SSRF默认仅允许回环；外连使用域名白名单、确认和超时L3 能力
SQL 注入SQL 白名单只读，参数化查询L1 数据
不可信内容AI 生成的 Markdown 经消毒器处理后才写入L3 能力
权限提升viewer 角色禁止 MCP 写入和 AI 写入L3 能力
