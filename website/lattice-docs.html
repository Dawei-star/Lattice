关于 格物 Lattice

Lattice 是一款本地优先的双链笔记知识库。它把 Markdown 笔记、关系图谱、可视化白板和 AI 助手放在同一个工作区，让知识留在自己的设备上，也让思考保持连贯。

本地优先 Markdown 源文件 Windows 无需注册

把零散想法，整理成可继续的知识。

在本地写下、连接、检索和复用，让工具服务于思考本身。

Markdown可读、可迁移 SQLite可重建索引 AI按需连接模型

为长期工作而设计

Lattice 的核心不是把功能堆在一起，而是让你的知识库在几年后依然可读、可带走、可继续。

数据掌握在你手里
01 / LOCAL

内容属于你

笔记以 Markdown 文件保存，默认无需联网，换设备也能带走自己的 Vault。

02 / LINKED

知识自然连接

双向链接、标签、嵌入和关系图谱，让一条笔记成为知识网络的一部分。

03 / OPEN

底层保持透明

SQLite 只负责可重建索引，核心内容仍是普通文件，不被专有数据库锁定。

核心功能

从一篇笔记开始，到一个可以检索、连接、推演的知识工作区。

Markdown 编辑

编辑、分栏、预览三种模式，900ms 静默自动保存，内容始终以可读文件为源。

双向链接与图谱

支持 `[[标题]]`、别名和小节链接，自动生成反向链接与可拖拽的知识关系图。

中文全文检索

SQLite FTS5 + trigram 分词，支持中文子串匹配，搜索结果会高亮命中的关键词。

本地白板

用 `.canvas` 文件保存卡片和连线，支持拖拽、缩放、对齐与笔记、图片之间的连接。

AI 知识库助手

基于关键词与语义混合检索进行问答，回答带来源引用，也支持写作、摘要、翻译与文件操作。

MCP Server

通过 stdio 向外部 Agent 暴露笔记读写工具，让 Claude 等客户端可以访问你的知识库。

界面预览

一个安静、密度可调的工作区：左边组织内容，中间专注写作，右边查看关系与上下文。

Workspace

让笔记回到工作流里

目录树、笔记列表、标签页、编辑器和关系面板在一个稳定的布局中协作，减少视线跳转。

Canvas

把线性笔记变成空间关系

用卡片和连线快速整理问题、方案、参考资料，再把关系落回可检索的笔记。

Assistant

问自己的知识库

AI 只在你配置并发起请求时联网，并把回答涉及的笔记来源展示出来，便于回看与核验。

工作方式

内容、索引与 AI 能力各司其职，既保持本地文件的自由，也保留现代工具的效率。

01

写入 Vault

笔记、附件和白板直接写入你选择的本地文件夹，格式清晰，随时可以复制或备份。

02

建立索引

SQLite 维护可重建的搜索、标签、链接和语义索引，让大量内容依然容易找到。

03

按需调用 AI

配置外部模型后，只有 AI 对话与 embedding 会按你的选择发送到对应服务。

隐私与数据边界

默认离线不是一句口号，而是应用的默认状态。联网能力需要你主动配置或点击触发。

本地优先，按需联网

你可以把 Lattice 当作一个完全本地的 Markdown 工作区使用。AI 能力是可选层，不会改变笔记文件的归属。

  • 无需注册账号，也没有默认云端同步。
  • API Key 只保存在本机，不写入日志或操作审计记录。
  • AI 文件操作需要预览与确认，任务模式也会留下审计痕迹。

技术构成

前端、服务端与数据文件边界清楚，方便调试，也方便在未来替换其中的一层。

Web

React 18 + Vite 5，组件按工作区、编辑器、图谱、白板和 AI 助手拆分。

Server

Express 5 + Node.js 内置 SQLite，模块按 routes / controller / service / repository 分层。

Search

SQLite FTS5 trigram 处理中文子串匹配，短词查询使用 LIKE 兜底复核。

Graph

原生 Canvas 渲染关系图与本地白板，保持拖拽、缩放和连线交互的轻量。

快速开始

发行版用户直接运行 Windows 安装版即可。下面的命令适用于开发、调试和二次开发。

PowerShell / Terminal 
# 安装前后端与 MCP 依赖
npm run setup

# 初始化本地索引数据库
npm run db:migrate

# 启动开发模式：前端 5173，后端 5177
npm run dev
