## 一、安装与启动

### 1.1 两个版本怎么选

| | 安装版 `Lattice-0.1.0-setup.exe` | 绿色版 `Lattice-0.1.0-portable.exe` |
| --- | --- | --- |
| 安装 | 需要走安装向导 | 免安装，双击即用 |
| 管理员权限 | 不需要（装在当前用户目录） | 不需要 |
| 开始菜单 / 桌面快捷方式 | 自动创建 | 无，自己放个快捷方式即可 |
| 笔记库位置 | `%APPDATA%\Lattice\data\` | **exe 同级的 `LatticeData\data\`** |
| 换机器 / 带走数据 | 需要手动拷数据目录 | 整个文件夹拷走就行 |
| 适用场景 | 长期自用，装完不管 | 放在 U 盘、多机同步、不想污染系统 |

**建议**：日常使用选安装版；需要随身携带或想「一份文件夹 = 一个知识库」选绿色版。

### 1.2 安装版

1. 双击 `Lattice-0.1.0-setup.exe`。
2. 安装向导可**自选安装目录**；默认装在当前用户目录下，因此不会弹 UAC 提权框。
3. 安装向导会提供创建桌面快捷方式与开始菜单项的选项（默认勾选）。
4. 完成后从桌面或开始菜单启动「格物 Lattice」。

### 1.3 绿色版

1. 把 `Lattice-0.1.0-portable.exe` 放到一个**你有写权限的文件夹**里（例如 `D:\Tools\Lattice\`）。
2. 双击运行。首次启动会在同级目录自动建出 `LatticeData\`。

> **不要**把绿色版直接放进 `C:\Program Files\` 这类只读位置——写不进去时它会自动把数据回退到
> `%APPDATA%\Lattice\`，这样就不再「便携」了。真遇到这种情况，日志里会有记录。

### 1.4 首次启动会发生什么

- 自动建库并执行数据库初始化，**无需任何手动配置**。
- 自动写入一套互相关联的示例知识库，避免面对空白界面：
  - 2 个目录：`开始使用`、`工程笔记`
  - 6 篇笔记：`欢迎使用格物`（已置顶）、`双向链接是什么`、`关系图谱怎么看`、
    `架构分层说明`、`全文检索实现`、`未归档的想法`
- 示例内容只是演示用，随时可以删掉，删完不会再生。
- **只有首次启动（数据库文件不存在时）才会灌入示例数据**，之后不会再动你的库。

启动时窗口会短暂延迟出现（先起本地服务、加载页面，再显示窗口，避免白屏闪烁）。
正常情况下 1–3 秒内完成。

### 1.5 启动时的几个行为约定

- **单实例**：软件同时只允许开一个。重复双击不会开第二个，而是把已有的窗口拉到最前面。
- **关窗即退出**：没有托盘常驻，关闭窗口等于完全退出，本地服务同时停止。
- **本地端口**：内部服务优先绑定 `127.0.0.1:5188`；若被占用会自动改用系统分配的随机端口，
  不需要你干预，也不会和别的东西抢端口。
- **不对外暴露**：服务只监听 `127.0.0.1`，局域网内其他机器访问不到。

## 二、界面导览

窗口默认 1280×820，最小可缩到 940×600。

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏  格物 Lattice │ 🔍 全文检索… │ 笔记/图谱 │ Ctrl+K 新建… │
├────────────┬─────────────────────┬───────────────────────────┤
│ 侧栏       │ 笔记列表            │ 编辑区                    │
│            │                     │                           │
│ · 目录树   │ · 标题 + 摘要       │ · 标题输入框              │
│ · 标签云   │ · 标签 / 反链数     │ · 编辑 / 分栏 / 预览      │
│ · 统计     │ · 置顶标记          │ · 保存状态提示            │
│            │                     │                           │
│            │                     ├───────────────────────────┤
│            │                     │ 关系面板（可收起）        │
│            │                     │ · 出链 / 反向链接 / 悬空  │
└────────────┴─────────────────────┴───────────────────────────┘
```

### 2.1 顶栏

从左到右依次是：

| 元素 | 作用 |
| --- | --- |
| 「格」字标 + 标题 | 品牌区，无交互 |
| 检索框 | 全文检索，输入即搜（有防抖）；右侧 `×` 一键清空 |
| 笔记 / 图谱 | 两个主视图切换 |
| `Ctrl` `K` 按钮 | 打开快速切换面板 |
| 新建笔记 | 新建一篇空白笔记并立即进入编辑 |
| ↻ 刷新按钮 | 重新拉取全部数据（标题、目录、标签、统计、图谱） |
| ☰ 面板按钮 | 展开 / 收起右侧关系面板 |
| ☀ / ☾ | 切换浅色 / 深色主题 |

### 2.2 侧栏

- **目录树**：任意层级嵌套。悬停可**就地重命名**、新建子目录、删除。
- **标签云**：点标签即筛选出所有带该标签的笔记。
- **统计**：笔记总数、目录数、标签数、链接数等总览数据。

### 2.3 笔记列表

每行显示标题、正文摘要、标签、反向链接数量；置顶的笔记排在最前并带置顶标记。
点击任意一行即在右侧打开。

### 2.4 编辑区

- **标题框**：直接改，改完自动保存。
- **模式切换**：`编辑`（纯文本）/ `分栏`（左写右看，默认）/ `预览`（只读渲染）。
  分栏模式下两侧滚动位置会同步。
- **状态提示**：会依次显示「未保存 → 保存中 → 已保存」，保存失败会明确报错而不是静默吞掉。
- **操作按钮**：置顶、移动到其他目录、删除。

### 2.5 关系面板

展示当前笔记与其他笔记的关系：

- **出链**：本篇正文里 `[[引用]]` 了谁。
- **反向链接**：谁引用了本篇（会自动维护，不需要手工登记）。
- **悬空链接**：你引用了但**还不存在**的笔记，点一下就能补建。

### 2.6 图谱视图

把所有笔记和引用关系画成一张网：

- 节点大小按连接数（度数）缩放，一眼看出哪些是枢纽笔记。
- 鼠标**拖拽**节点、**滚轮**缩放、**点击**节点直接跳到那篇笔记。
- 适合发现「孤岛笔记」（没有任何连接的）和意料之外的关联。

## 三、日常操作

### 3.1 新建与保存

- `Ctrl + N` 新建，或在顶栏点「新建笔记」。
- **自动保存**：停止输入约 0.9 秒后静默存盘，不需要手动保存。
- `Ctrl + S` 可立即保存（比如写完最后一句就想马上落盘）。
- 标题留空时不会提交标题（服务端拒绝空标题），正文照常保存。

### 3.2 双向链接（核心功能）

在正文里用双方括号引用其他笔记：

| 写法 | 效果 |
| --- | --- |
| `[[笔记标题]]` | 链接到该笔记 |
| `[[笔记标题\|显示文字]]` | 链接到该笔记，但显示成别的文字 |
| `[[笔记标题#小节名]]` | 指向该笔记里的某个小节 |

- 目标笔记不存在时，这条链接会被标成**悬空链接**，在关系面板里可一键创建。
- 链接是**从正文自动解析**的，不需要手动维护任何关系表。改了正文，链接就跟着变。
- 被引用的笔记删掉后，指向它的链接会退回悬空状态而**不是消失**——引用关系不会凭空断掉。

### 3.3 嵌入引用

独占一行的 `![[笔记标题]]` 会把那篇笔记的内容**内嵌**显示进来，而不是只给一个链接。

- 支持两级嵌套。
- 会自动检测循环引用（A 嵌 B、B 又嵌 A），不会无限递归。

### 3.4 标签

在正文里直接写 `#标签` 即自动归类。支持嵌套写法 `#工程/前端`、`#工程/后端`，
侧栏标签云里按层级展示。标签同样是正文派生数据，删掉正文里的标签，归类自动消失。

### 3.5 快速切换

按 `Ctrl + K` 打开快速切换面板，输入标题片段模糊匹配、回车跳转。

**目标笔记不存在时可以直接创建**——这是最常用的写笔记姿势：想到一个概念，
`Ctrl+K` 输入名字、回车，边写边把新笔记链上。

### 3.6 全文检索

顶栏检索框输入即搜，结果带关键词高亮。

关于中文检索的一个说明：

- 中文采用 **SQLite FTS5 + trigram 分词**，支持子串匹配——搜「知识」能命中「知识管理」。
- **两个字的短查询会自动改用模糊匹配兜底**（trigram 需要至少 3 个字符才能建索引）。
  所以「笔记」这种两字词也能搜到，只是走的是另一条路径。
- 搜不到时不要怀疑软件：先试试把关键词写长一点。

### 3.7 目录与整理

- 目录可任意层级嵌套。
- 目录可以就地重命名、删除。
- **删除目录不会删除里面的笔记**——笔记会自动回到「未分类」，不会丢。

### 3.8 主题

点顶栏的 ☀ / ☾ 切换浅色 / 深色。选择会记住，下次打开直接生效，
并且首屏渲染前就定好主题，不会出现先白后黑的闪烁。

## 五、数据、备份与迁移

### 5.1 数据放在哪

| 版本 | 笔记库 | 完整数据目录 |
| --- | --- | --- |
| 安装版 | `%APPDATA%\Lattice\data\lattice.db` | `%APPDATA%\Lattice\` |
| 绿色版 | `<exe 所在目录>\LatticeData\data\lattice.db` | `<exe 所在目录>\LatticeData\` |

`%APPDATA%` 的完整路径通常是 `C:\Users\<你的用户名>\AppData\Roaming`。

**快速定位**：在资源管理器地址栏直接粘贴 `%APPDATA%\Lattice` 回车即可。

数据目录内容：

```
Lattice/
├── data/lattice.db      笔记库（所有笔记、目录、标签、链接都在这一个文件里）
└── logs/lattice.log     运行日志
```

### 5.2 备份

最稳的做法是**在软件关闭的状态下，整个目录拷走**：

- 安装版：复制 `%APPDATA%\Lattice\` 到别处
- 绿色版：复制整个软件文件夹

如果只想备份笔记库本体，复制单个 `data\lattice.db` 也可以——
这是一个标准的 SQLite 文件，用任何 SQLite 工具都能直接打开查看或导出。

> 之所以建议先关软件再拷：数据库使用 WAL 模式，运行中会同时存在
> `lattice.db-wal` 等辅助文件。运行中拷贝可能拿到不完整的中间状态。

### 5.3 换机器

**绿色版**：把整个文件夹拷到新机器，双击 exe 即可，笔记原样都在。
这是它真正便携的地方。

**安装版**：在新机器上装好，先**启动一次再关掉**（让它建出目录结构），
然后把旧机器的 `data\lattice.db` 覆盖过去即可。

### 5.4 恢复

把备份的 `data\lattice.db` 覆盖回原位，重启软件。就这么简单，没有导入导出流程。

## 六、设置与日志

### 6.1 可以调的东西

桌面版**刻意做成零配置**：不需要改任何文件就能用。仅有一个环境变量供高级排查使用：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `LATTICE_LOG_LEVEL` | `info` | 日志详细程度：`debug` / `info` / `warn` / `error` |

要排查问题时，可以先设置成 `debug` 再启动，日志会详细很多：

```bat
set LATTICE_LOG_LEVEL=debug
Lattice-0.1.0-portable.exe
```

### 6.2 日志文件

- 位置：数据目录下的 `logs\lattice.log`
- 内容：启动步骤、数据库迁移、每一次页面请求、界面里发生的错误，全部按行记录
- **超过 2MB 自动轮转**为 `lattice.log.1`，不会无限增长

日志是排查问题唯一的线索来源（桌面软件没有控制台），
反馈问题时附上这个文件即可。

## 七、升级与卸载

### 7.1 升级

- **安装版**：直接用新版 `setup.exe` 覆盖安装即可，**笔记数据不受影响**。
- **绿色版**：用新版 exe 替换旧的 exe，保留 `LatticeData\` 目录不动。

数据库结构升级在启动时自动完成，旧库会被平滑迁移，不需要手动操作。

### 7.2 卸载

**安装版**：设置 → 应用 → 找到「格物 Lattice」→ 卸载。
也可以从开始菜单里的卸载快捷方式进入。

> **卸载时你的笔记会被保留**。这是刻意的设计——避免手滑卸载把笔记库一起删掉。
> 如果确实要彻底清除，卸载后手动删除 `%APPDATA%\Lattice\` 目录。

**绿色版**：直接删掉文件夹就卸载完了。删之前记得把 `LatticeData\` 挪走或备份，
那里面是你的笔记。

## 八、故障排查

### 8.1 双击没反应 / 闪一下就没了

最常见的原因是当前系统环境**拦截了 Chromium 的 GPU 子进程沙箱**，
多见于：受限的虚拟机、远程桌面会话、安全软件的深度防护模式。

软件内置了**自愈机制**：

1. 第一次启动若 GPU 进程反复崩溃，会在数据目录落下标记并退出。
2. **再启动一次即可**——检测到标记后会自动关闭 GPU 沙箱（仅影响 GPU 进程，
   笔记功能完全不受影响），窗口正常打开。

所以遇到这种情况：**再双击一次**。若第二次仍然打不开，请继续看下一条。

### 8.2 窗口一片空白，或弹出「界面无法渲染」

如果界面进程连续崩溃 3 次，软件会弹出明确提示并告知日志位置，而不是让你对着白屏发呆。

处理办法：

1. 把本程序加入安全软件的信任 / 白名单（重点检查主动防御、沙箱类功能）。
2. 尽量在本机物理桌面会话下运行，而不是远程桌面或受限虚拟机。
3. 弹出提示时，按提示路径取 `logs\lattice.log`，里面会记录崩溃原因。

### 8.3 提示「页面加载失败」

说明本地服务没能正常起来。按顺序排查：

1. 是否有另一个实例已经在运行？软件是单实例，重复启动只会聚焦已有窗口。
2. 端口 `5188` 被别的程序占用了？正常情况下会自动改用随机端口，
   若仍失败，关掉可疑程序后重试。
3. 检查 `logs\lattice.log` 里有没有数据库相关报错。

### 8.4 提示「启动失败」

启动时会集中校验全部配置，任何一项非法都立即报错并退出，而不是带病运行。
弹窗里会写明确原因和日志路径。

### 8.5 数据找不到了

先确认用的是哪个版本——安装版和绿色版的数据**不在同一个地方**（见 [5.1](#51-数据放在哪)）。
绿色版如果被放在了只读目录里，数据会自动回退到 `%APPDATA%\Lattice\`，
去那里找找。

### 8.6 中文搜索搜不到

- 两个字的短词走模糊匹配，能搜到但结果可能不如长词精准。
- 尝试把关键词加长（3 个字以上会走全文索引，匹配质量更好）。
- 确认关键词确实出现在笔记正文或标题里——检索范围是标题 + 正文。

### 8.7 杀毒软件报警

Electron 打包的桌面程序偶尔会被误报，尤其是新发布的、没有数字签名的版本。
把程序目录加入信任列表即可，不影响功能。

### 8.8 菜单栏不见了

菜单栏默认自动隐藏（避免占版面）。**按一下 `Alt` 键**就会显示出来，里面有
文件 / 编辑 / 视图三组菜单，以及「开发者工具」和「全屏」等入口。

### 8.9 需要提交问题时请附上这些

1. 你用的是安装版还是绿色版
2. `logs\lattice.log`（如果有 `lattice.log.1` 也一起）
3. 具体现象：什么时候出现、窗口上显示了什么

## 九、已知限制

当前版本的边界，都是刻意划定的：

| 限制 | 说明 |
| --- | --- |
| 附件删除非自动 | 图片 / PDF 已可存进笔记库并统一管理；但删除笔记不会连带删掉其附件（可能被别处复用），需在「附件」面板手动删除或一键「清理未引用」 |
| 版本历史是快照 | 编辑区「历史」可预览并回滚到此前自动保存的内容；但它是按时间节流、每篇限量保留的整篇快照，不是逐字改动记录，重要内容仍建议自行备份 |
| 无实时协作 | 单机单用户设计，没有多端同步与协同编辑 |
| 图谱规模 | 数百到数千节点流畅；上万节点需要换近似算法 |
| 仅 Windows | 目前只产出 Windows 版本 |
| 数据格式 | 知识库是 SQLite 单文件，不是 Markdown 文件夹，不能用 Obsidian 直接打开 |

> 最后一条值得强调：**这不是 Obsidian 的兼容替代品**。它借鉴了双链笔记的交互体验，
> 但数据存在一个 SQLite 库里。库文件可以用任何 SQLite 工具打开导出，
> 但没有「一堆 .md 文件躺在文件夹里」那种形式。

## 附录：关于隐私

- 软件**不联网**，没有遥测、没有账号、没有云同步。
- 本地服务只监听 `127.0.0.1`，局域网内其他设备无法访问。
- 所有笔记、标签、链接关系都在你机器上的那一个 `lattice.db` 文件里。
- 笔记正文里的外部链接点击后会交给系统默认浏览器打开，笔记界面本身不会被导航走。
